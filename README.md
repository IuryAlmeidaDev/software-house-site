---

## 📌 Sobre o Projeto

Interface web moderna, responsiva e performática construída para apresentar os serviços de desenvolvimento sob medida, cases de sucesso e captação de clientes da software house N&A. Conta com animações fluidas via **Framer Motion** e design refinado com **Tailwind CSS**.

## 🚀 Funcionalidades

- ✨ **Design Moderno:** Efeitos visuais suaves com Framer Motion e tipografia pensada para legibilidade.
- 📱 **100% Responsivo:** Otimizado para smartphones, tablets e monitores widescreen.
- 📬 **Formulário de Contato:** Validação estrita de formulários com React Hook Form.
- ⚡ **Alta Performance:** Build ultrarrápido impulsionado por Vite.

## 🛠️ Tecnologias Utilizadas

- **React 18** & **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Framer Motion** & **Lucide React**

## ⚙️ Como Executar Localmente

```bash
git clone https://github.com/IuryAlmeidaDev/software-house-site.git
cd software-house-site
npm install
npm run dev
```
